# Модель движения: Random Walk

В данной работе реализована модель случайного блуждания (Random Walk).

## Формулы

x += speed * cos(angle)
y += speed * sin(angle)

Каждую секунду человек случайным образом изменяет направление и перемещается на вектор длиной `v`.

## Структура файлов

- **Movable.kt**  
  Интерфейс, описывающий движущиеся объекты.  
  Содержит свойства:
    - `x`, `y` — координаты объекта
    - `speed` — скорость движения  
      И метод:
    - `move()` — определяет алгоритм движения

- **Human.kt**  
  Класс, реализующий интерфейс `Movable`.  
  Моделирует человека, который перемещается случайным образом (по случайному углу).

- **Driver.kt**  
  Класс-наследник `Human`.  
  Добавляет поле `carModel` и переопределяет метод `move()`, чтобы движение было прямолинейным вдоль оси X.

- **Main.kt**  
  Точка входа.  
  Создаёт несколько объектов `Human` и один объект `Driver`.  
  Организует их параллельное движение с помощью `Thread`.
